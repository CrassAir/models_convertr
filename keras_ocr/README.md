# Дообучение keras-ocr для работы с ТТН (Товарно-транспортная накладная)

Этот проект содержит код для дообучения моделей keras-ocr для определения ключевых данных на товарно-транспортных накладных (ТТН) и распознавания текста в этих данных.

## Требования к системе

- Python 3.10.10
- CUDA-совместимая GPU (рекомендуется для обучения)
- Минимум 8 GB RAM
- Свободное место на диске: 5+ GB

## Установка

### 1. Создание виртуального окружения

```bash
python3.10 -m venv ttn_ocr_env
source ttn_ocr_env/bin/activate  # Linux/Mac
# или
ttn_ocr_env\Scripts\activate  # Windows
```

### 2. Установка зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt

# Для GPU поддержки (опционально):
pip install tensorflow-gpu>=2.8.0,<2.16.0
```

### 3. Установка keras-ocr

```bash
# Если возникают проблемы с keras-ocr на Python 3.10:
pip install image-ocr  # Совместимая версия для Python 3.10

# Или стандартная установка:
pip install keras-ocr
```

## Подготовка данных

### Формат аннотаций

Создайте файл `annotations.json` с разметкой ваших изображений ТТН:

```json
[
  {
    "image_name": "ttn_001.jpg",
    "fields": [
      {
        "field_type": "номер_накладной",
        "text": "№ 012345",
        "x1": 150, "y1": 50, "x2": 250, "y2": 80
      },
      {
        "field_type": "дата_составления",
        "text": "15.10.2024",
        "x1": 300, "y1": 50, "x2": 400, "y2": 80
      },
      {
        "field_type": "грузоотправитель",
        "text": "ООО Ромашка",
        "x1": 100, "y1": 120, "x2": 300, "y2": 150
      }
    ]
  }
]
```

### Поддерживаемые поля ТТН

- `номер_накладной` - Номер товарно-транспортной накладной
- `дата_составления` - Дата составления документа
- `грузоотправитель` - Наименование отправителя груза
- `грузополучатель` - Наименование получателя груза
- `наименование_груза` - Описание перевозимого груза
- `количество_мест` - Количество грузовых мест
- `масса_груза` - Масса груза в килограммах
- `стоимость_груза` - Стоимость груза в рублях
- `водитель` - ФИО водителя
- `автомобиль_номер` - Государственный номер автомобиля
- `путь_следования` - Маршрут перевозки

## Обучение моделей

### 1. Обучение детектора текста

```bash
python ttn_detector_training.py
```

Параметры можно изменить в коде:
- `data_dir` - путь к папке с изображениями
- `annotations_file` - путь к файлу аннотаций
- `epochs` - количество эпох обучения
- `batch_size` - размер батча

### 2. Обучение распознавателя текста

```bash
python ttn_recognizer_training.py
```

Эта модель обучается распознавать текст в областях, найденных детектором.

### 3. Использование обученных моделей

```bash
python ttn_pipeline.py
```

Пайплайн объединяет обе модели для полной обработки ТТН.

## Результаты

После обучения будут созданы файлы:
- `ttn_detector_best.h5` - веса лучшей модели детектора
- `ttn_recognizer_best.h5` - веса лучшей модели распознавателя
- `*.log` - логи обучения
- `ttn_results.json` - результаты распознавания в JSON
- `ttn_visualization.png` - визуализация результатов

## Рекомендации по улучшению качества

### Подготовка данных:
1. Используйте качественные изображения (разрешение 300+ DPI)
2. Обеспечьте хорошее освещение при сканировании
3. Разметьте минимум 500+ изображений для каждого типа поля
4. Включите различные типы ТТН и почерков

### Аугментация:
1. Поворот изображений (±5 градусов)
2. Изменение яркости и контрастности
3. Добавление шума
4. Перспективные искажения

### Обучение:
1. Используйте early stopping для избежания переобучения
2. Мониторьте loss на валидационной выборке
3. Экспериментируйте с learning rate
4. Используйте GPU для ускорения

## Устранение проблем

### Ошибки установки:
```bash
# Если keras-ocr не устанавливается на Python 3.10:
pip install image-ocr

# Проблемы с OpenCV:
pip install opencv-python-headless

# Проблемы с TensorFlow:
pip install tensorflow==2.8.0 --force-reinstall
```

### Ошибки обучения:
1. **OutOfMemoryError**: Уменьшите batch_size
2. **Низкое качество**: Увеличьте датасет, улучшите разметку
3. **Медленное обучение**: Проверьте использование GPU

## Метрики качества

Для оценки качества моделей используются:
- **Accuracy** - точность распознавания отдельных символов
- **Edit Distance** - расстояние редактирования между предсказанием и истиной
- **Field Detection Rate** - процент правильно найденных полей
- **End-to-End Accuracy** - полная точность извлечения данных из ТТН
