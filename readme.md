# Проект Smart Build Control Pro

Проект представляет собой систему распознавания транспортных накладных (ТН) на базе искусственного интеллекта.

## Компоненты системы
- Модель детекции YOLO11 — обученная нейросеть для распознавания полей документов
- Размеченный датасет — коллекция изображений ТН в формате COCO
- Android-приложение — мобильное приложение в формате .apk
- Библиотека распознавания — интеграция google_mlkit_text_recognition для извлечения текста

## Инструкция по использованию
- Сфотографируйте транспортную накладную с помощью камеры устройства
- Добавьте полученное фото в приложение через интерфейс
- Система автоматически обработает изображение и отобразит:
- Визуальную разметку распознанных полей документа
- Извлеченный текст из каждого классифицированного поля

Приложение работает полностью офлайн, обеспечивая быструю обработку документов без необходимости интернет-соединения.
