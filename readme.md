# Проект Smart Build Control Pro состоит из 
- Обученной модели детекции на база YOLO11
- Размеченом датасете ТН в формате COCO
- Приложения .apk для android
- Библиотеки google_mlkit_text_recognition

## Как пользоваться
- Сфотографировать ТН
- В интерфейсе добавить фото
- После отобразится визуальное отображение классифицированых полей и распознаный текст
